# 鹅码通展示原型 V0.2

> H5 V0.3 为国内“微信 H5 + 政务民生服务”布局的黑白灰中保真功能原型；功能确认后再进行视觉定稿。PC 后台仍沿用 V0.1。

## 打开方式

直接双击 `index.html`，或在本目录启动任意静态文件服务器后访问。

- `h5-prototype.html`：三 Tab H5 展示原型（V0.2）。
- `pc-admin-prototype.html`：PC 管理后台展示原型。
- `prototype-spec.md`：首轮范围、角色权限和待确认问题初稿。
- `design-tokens.json`：颜色、间距和圆角等设计变量。

原型不依赖外部字体、图标库或图片资源；图标以本地内联 SVG 提供，断网可打开。

## 展示流程

### H5

1. 摊位信息：模拟扫码进入王记时令鲜蔬摊，查看摊主上传照片、管理侧规范评分、公开信息和公示证照；不包含用户评价系统。
   - 公示证照暂使用带“鹅码通 · 仅供原型展示”水印的虚构图片，正式业务由后台上传真实证照。
2. 老鹅地图：搜索附近摊位和织补、修车、开锁、公厕、停车位等服务，点击分类筛选不同 Icon 点位。
3. 我的：登录后选择未认证用户、摊主、执法者身份，查看对应个人记录与工作能力。
4. 摊主演示：切换到摊主，从“我的摊位”进入本人摊位，通过“编辑我的摊位信息”提交变更审核。

### PC 后台

1. 数据看板：从今日优先事项跳转审核、投诉和检查。
2. 摊点档案：新增摊点、查看档案详情。
3. 审核管理：对比原值与新值，通过或驳回申请。
4. 检查管理：查看检查、整改和复查状态。
5. 投诉反馈：完成受理、分派、核实和办结展示流程。

## 原型边界

- 本版仅用于需求沟通与 UI 展示，不连接真实接口、数据库或高德地图 API。
- 页面操作在当前浏览器内模拟，不保存真实数据。
- 行政处罚仅展示“记录结果”，不模拟正式执法程序。
- 角色权限和状态规则采用 `prototype-spec.md` 中的初稿，后续需按 Q001–Q021 确认。

## 适配基线

- PC：1366、1440、1920 宽度；125% 缩放。
- H5：375×812、390×844、430×932。
- PC 在小屏下会收起侧栏并保证表格横向滚动，不撑破页面。
